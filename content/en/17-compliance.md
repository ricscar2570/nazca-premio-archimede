## 17.1  Requirements checklist

| Competition requirement | Required value | NAZCA v3.1 status |
|------------------------|---------------|-------------------|
| Original and unpublished game | Yes | ✓ Confirmed |
| Maximum duration | ≤ 90 minutes | ✓ Target 45–75 min |
| Box dimensions | ≤ 40×30×10 cm · rigid cardboard | ⚠ Board 25×33 cm: 33 cm exceeds the 30 cm limit. Verify with Studiogiochi or solve by reducing board to 25×25 cm. |

| No cylindrical containers | Rectangular box shape | ✓ Standard rectangular box |
| Functional components | Standing pieces, adequate spaces | ✓ Stable pegs, 12.5mm nodes |
| Rulebook | ≤ ~10,000 characters · Italian | To write — in progress |
| Name and contacts on box | Surname and first name, phone, email | To add: [NAME][PHONE][EMAIL] |

| Base game only (no variants) | Jury ignores expansions | ✓ Base mechanic only |

## 17.2  Residual risks

| Risk | Probability | Mitigation |
|------|-------------|------------|
| Rulebook > 10,000 characters | HIGH | Write a compact version dedicated to the jury — separate from this document |
| Geoglyph recognisability at Revelation | MEDIUM | Test legibility with at least 5 sessions before submission. Increase grid step if necessary. |
| Clan balance not physically validated | MEDIUM | 30 physical playtest games before deadline. Document every session. |
| Cord tangling | LOW | Quercetti combination already validated. Monitor with 4 simultaneous clans. |
