# PART X — GEOMETRIC OBJECTIVES

## 10.1  Mechanic

At the start of the game, 3 geometric objective cards are revealed from the deck of 12. These objectives are open to all players: anyone who achieves the required shape with their peg-cord network earns the points. It is not an exclusive objective — two players can complete the same objective in different rounds.

Verification happens in real time: as soon as a player plants the last peg completing the shape, they announce it, the configuration is visually verified, and they take the objective card (+3 points).

Canonical value: +3 points per completed objective.

## 10.2  The 12 objective cards

| Objective | Condition |
|-----------|-----------|
| N–S Line | 6+ consecutive nodes in the same column (vertical) |
| E–W Line | 6+ consecutive nodes in the same row (horizontal) |
| Diagonal | 7+ consecutive nodes in a 45° diagonal |
| Cross | Two perpendicular lines that intersect (min 3+3 nodes each) |
| Spiral | 8+ nodes forming a closed spiral |
| Triangle | Three cord segments forming a closed triangle |
| Square | Four sides of 3+ nodes each, 90° corners |
| Zig-Zag | 4+ direction changes at 90° in sequence |
| Large L | Two perpendicular segments of 5+ nodes each |
| Fork | One node with 3+ branches in different directions |
| Double Loop | Two parallel lines connected at both ends |
| Grid | 3×3 grid with all edges connected |
