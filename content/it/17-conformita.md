# PARTE XVII — CONFORMITÀ BANDO ARCHIMEDE 2027

## 17.1  Checklist requisiti

| Requisito bando | Valore richiesto | Stato NAZCA v3.1 |
|-----------------|-----------------|-----------------|
| Gioco originale e inedito | Sì | ✓ Confermato |
| Durata massima | ≤ 90 minuti | ✓ Target 45–75 min |
| Dimensione scatola | ≤ 40×30×10 cm · cartone rigido | ⚠ Plancia 25×33 cm: 33 cm supera il limite di 30 cm. Da verificare con Studiogiochi o risolvere con riduzione plancia a 25×25 cm. |
| No scatole in legno/metallo | Cartone o plastica | ✓ Quercetti + cartone |
| No contenitori cilindrici | Forma parallelepipedo | ✓ Scatola rettangolare standard |
| Componenti funzionali | Pedine in piedi, caselle adeguate | ✓ Chiodini stabili, nodi 12.5mm |
| Regolamento | ≤ ~10.000 battute · italiano | Da scrivere — in progress |
| Nome e contatti su scatola | Cognome e nome, tel, email | Da aggiungere: [NOME][TEL][EMAIL] |
| Lingua | Italiano (EN obbligatoria se finalisti) | ✓ Italiano |
| Solo gioco base (no varianti) | La giuria ignora espansioni | ✓ Solo meccanica base |

## 17.2  Rischi residui

| Rischio | Probabilità | Mitigazione |
|---------|-------------|-------------|
| Regolamento > 10.000 battute | ALTA | Scrivere versione compatta dedicata alla giuria — separata da questo documento |
| Riconoscibilità geoglifi alla Rivelazione | MEDIA | Testare leggibilità con almeno 5 sessioni prima della spedizione. Aumentare step griglia se necessario. |
| Bilanciamento clan non validato fisicamente | MEDIA | 30 partite fisiche di playtest prima della deadline. Documentare ogni sessione. |
| Aggrovigliamento cordicelle | BASSA | Combinazione Quercetti già validata. Monitorare con 4 clan simultanei. |
